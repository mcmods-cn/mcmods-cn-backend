# 供应商导入历史结果只读盘点（TP-001）

该工具检查 `mod_metadata_import_jobs` 中仍保存 result 或非空 error 的记录。旧版共享供应商凭据曾可能把非公开资料写入 result；旧 error 也可能包含上游响应正文。工具只产生待核查候选，**不把所有历史结果认定为隐私泄露**。

必须显式设置 `DATABASE_URL` 和至少 32 字节的 `MCMODS_SOURCE_AUDIT_HMAC_KEY`，并选择 schema、一个创建者公开 ID 或一个任务公开 ID。连接失败不会输出连接字符串；输出只含任务公开 ID、种类、状态、时间、字节数和带用途分隔的 HMAC。来源 URL、结果及错误正文均不输出，也不请求任何供应商接口。

```sh
# 从已授权、已核验的连接环境运行；不要在命令行写数据库密码或 HMAC 密钥。
go run ./cmd/import-source-privacy-audit \
  --schema public \
  --actor-public-id abc123xyz \
  --max-jobs 1000 \
  --out /absolute/new-private-inventory.json
```

也可指定 `--job-public-id`；同时指定创建者和任务时取交集。上限是 100,000 条；默认 1,000 条。超过预算时 `hasMore=true`，不能把首批结果当作全部存量。输出文件以 0600 新建，已存在的文件会被拒绝覆盖。

每次查询明确使用 PostgreSQL `READ ONLY` 和 `REPEATABLE READ`，记录实际事务设置和快照。它不修改任务、结果、项目、资产、权限、流水或余额，因此没有数据库回滚步骤。重复执行可选择新的输出路径；相同 HMAC 密钥用于比对同一内容，换密钥后不能直接关联指纹。

处置前还需：用明确获授权的当前供应商事实判断来源可见性；核对原任务创建者、后续创建项目和复制/发布记录；确定合法保留、隔离或删除的业务范围；保护正常公开资料、人工内容和共享引用。当前工具未自动追踪复制/公开衍生内容，也无法撤回第三方已下载的内容。任何生产修复都需单独、可审查、有 dry-run/计数核对/补偿说明的方案。本任务仅在拥有权已核验的合成隔离库执行此工具，没有执行生产修复。
