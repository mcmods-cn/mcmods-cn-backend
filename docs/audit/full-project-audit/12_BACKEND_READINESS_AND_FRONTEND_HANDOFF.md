# 后端完成度与前端交接

## 最终判定

**结论 C：暂时不应正式转入以前端为主的开发阶段，应优先修复后端阻塞项。**

这一结论基于 791 / 791 文件、169,449 / 169,449 行的完整人工语义审查，取代 9.97% 高风险抽查阶段的中间结论 B。完整审计登记 176 个高风险 Finding ID，其中包括权限/IDOR、经济整数溢出、外部凭据转发、异步任务丢失、文件生命周期、审核可达性和无界资源消耗；这些不是仅靠前端容错可以规避的问题。

## 必须先修复的后端阻塞

1. `SEC-011`、`SEC-013`、`SEC-039`、`SEC-040`、`SEC-044`：外部凭据、跨项目关系 IDOR、经济守恒和权限残留。
2. `SEC-009`、`BUG-018`、`BUG-019`、`BUG-042`：导入身份、重导入撤销、任务恢复和爬虫事务一致性。
3. `LEGACY-006`、`LEGACY-008`、`LEGACY-009`、`LEGACY-013`、`LEGACY-019`、`OPS-019`：旧 Core NATS/进程任务路径迁移到权威 Outbox/JetStream。
4. `BUG-021`、`BUG-132`、`BUG-139`：审核队列固定截断导致合法待审对象不可达。
5. `SEC-007`、`SEC-010`、`SEC-014`、`PERF-004`：Markdown、图片、服务器探测和无界 goroutine 的资源耗尽。
6. `BUG-066`、`BUG-068`、`BUG-069`、`OPS-013`：MRPack 报告、依赖、收藏夹删除和 OSS 完成状态。
7. 为上述路径补数据库、权限、并发、故障测试；当前后端覆盖率 18.4%，前端没有测试。

## 可以并行进行的前端工作

- 设计 Token、排版、颜色、间距和响应式基础设施。
- 不改变业务协议的静态页面和公开展示组件视觉优化。
- 为后续修复准备测试框架、Mock Server、可访问性和视觉回归基础。
- 小范围复用改造可在对应后端契约已冻结后进行。

## 暂不应冻结或大改的前端领域

- 通知中心、翻译、未读和私聊实时状态。
- 项目权限、作者/团队关系、编辑员申请与后台授权。
- 收藏夹 MRPack、导入/导出、爬虫和自动更新任务。
- 审核队列、举报治理、日志/OSS、评论深页与资料大列表。
- 搜索、热度、统计和后台大数据列表。

## 后端成熟度矩阵

| 维度 | 最终评价 | 依据 |
| --- | --- | --- |
| 功能覆盖 | 广但未收口 | 功能面完整，多个领域仍有旧/新实现并存 |
| 认证 | 基础较好 | Session 与权限版本已拆分；安全状态路径仍需故障测试 |
| 权限 | 不满足发布门 | 确认跨项目 IDOR、角色来源丢失、轨道角色残留等高风险问题 |
| 数据一致性 | 不满足发布门 | 导入、爬虫、文件、MRPack 和关系更新存在事务/补偿缺口 |
| 安全 | 不满足发布门 | 47 个 SEC，其中多项高风险可直接影响凭据、权限、经济或资源 |
| 数据库 | 结构完整但健康度需改进 | 约束基础较强；存在无用表/字段、重复索引、缺失索引和不稳定写法 |
| 性能 | 不满足规模门 | 72 个 PERF；审核、日志、评论、通知、搜索等百万级风险明确 |
| 异步任务 | 不稳定 | JetStream 未启用；可靠 Outbox 与旧直发/进程路径并存 |
| 缓存 | 主模型合理、降级需改进 | 权限版本化 Key 正确；反滥用 Redis 降级为单实例 |
| 测试 | 明显不足 | Go 18.4%；前端 0；远程 PostgreSQL 集成已通过，Race/漏洞/JetStream 仍未完成 |
| 可观测性 | 需改进 | 多处错误被转换为空结果、零值或成功状态 |
| 前端交接 | 仅限低风险并行 | 业务契约仍会因高风险修复而变化 |

## 转向前端前的最低门槛

```text
修复高风险权限、IDOR、经济和凭据问题
统一可靠任务到 PostgreSQL Outbox + JetStream
修复审核队列可达性和关键无界查询
完成 JetStream、Redis 故障与并发测试；保留已通过的远程 PostgreSQL 集成质量门
完成 Race 和依赖漏洞扫描
建立前端关键流程自动化测试
Go test/vet/build、前端 typecheck/lint/build 全部通过
```

问题优先级与证据见 [11_FINDINGS_REGISTER.md](11_FINDINGS_REGISTER.md)，专项旧实现迁移见 [13_CODE_STYLE_MAPPING_AND_LEGACY_RESIDUE_AUDIT.md](13_CODE_STYLE_MAPPING_AND_LEGACY_RESIDUE_AUDIT.md)。
