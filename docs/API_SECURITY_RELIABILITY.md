# API 状态、会话和后台任务可靠性

## 会话和错误响应

Redis与进程缓存仅加速解析，PostgreSQL `auth_sessions` 活性以及用户认证版本决定会话是否有效。每次认证成功前执行DB校验，跨实例退出、封禁、密码版本变化和缓存删除失败不能继续授权；数据库故障返回可重试服务错误，不能伪装成已退出。退出将session撤销和presence删除放在同一事务，提交后才清cookie；失败保留cookie使用户可重试。SSE连接每20秒重验会话，重验查询最多5秒；撤销传播上界为一个心跳周期加查询等待，事件可能在下一次重验之前送达。失效或数据库错误关闭连接。完整access-log/gzip中间件保持ResponseController流式能力；每次帧写入及连接终止最多10秒写等待，避免普通HTTP WriteTimeout关闭正常长连接或无限等待慢客户端。

NATS设置更新先加密保存再重连。连接失败返回503、code=`nats_connection_failed`、details.saved=true，配置已保存，需要修正并重试。URL响应去掉所有userinfo/query/fragment/path；多server逐个处理。提交与当前脱敏URL相同表示保留原内部URL凭据；改变URL才替换。password/token响应仅标记存在。基础设施数据库指标失败返回503，不返回零值健康状态。

## 通知翻译

通知翻译指纹包含收件人、通知、原文updated_at/字段、目标语言和冻结术语版本。已有新鲜译文直接读取；源目标相同返回原文，均不调用AI。任务创建、用户/站点额度预留、并发去重与既有任务Outbox在同一事务。worker发布须仍有running任务、通知仍存在/可访问且原文快照未变。轮询GET不会重新持久化旧结果，不能覆盖更新后的或人工保存的译文。失败可按管理权限使用既有AI任务retry/cancel接口；恢复细节见AI专项文档。

## 文件、关注和经济

项目发行扩展名策略与文件登记一致，支持mrpack与实际项目的zip/jar；其他scope保持对应策略。完成接口采用OSS HEAD实际大小，拒绝空或超过2GiB对象。用户配额查询与上传登记在用户事务锁下进行，错误可重试，无法读取配额不能视作无限额度。生成对象的业务配额与直传并不完全等同。

关注返回实际notification设置，重复关注保留关闭通知选项。项目私有后可删除本人已有关注，DELETE不披露目标正文；状态/列表查询仍按当前资源可见性限制。数据库错误不应显示为成功或空数据。

经济税额使用整数ceil，金额乘积/余额相加检测bigint溢出。没有经济配置row使用既有默认值；读取失败、非对象/非法配置返回503，不能启用默认签到发币。商店权限/配置/目标独立读发生在事务前，事务只保护当前商品/库存/余额及写入，防止池饱和等待自身连接。公开数值契约仍为JSON number，超过JavaScript安全整数范围的客户端精度需跨端另行治理。

## 蓝图worker升级

新worker依赖前向repair `audit-2026-10-blueprint-worker-lease`。部署顺序：停止旧worker→迁移新增run_token/heartbeat_at→启动新worker；旧worker不具备迟到fence，不能滚动混跑。queued领取生成随机token，15秒心跳，processing超过5分钟无有效心跳可恢复queued；连续崩溃累计达到3次领取后进入failed终态，归一化资源仍processing且无另一个活动归一化任务时同步标失败。进度、发布和完成均检查当前token及状态，晚到的旧worker不能更新新的领取。删除蓝图不被worker恢复，单个convert失败保留原ready产物。新归一化对象按token命名，旧已登记对象URL仍可读取。

蓝图NBT解压最多256MiB、嵌套128层、总对象2,097,152；在交给NBT库分配前验证数组/list声明和真实字节边界。复杂结构可能先达到对象限制再达到独立8,388,608非空气方块限制。Sponge稀疏palette按真实条目存储，拒绝负/重复索引和未知引用，不以最高索引分配内存。

## 收藏导出和全局目录

收藏导出额度在同一用户事务锁下检查并创建任务；预检/依赖解析先关闭数据库rows再执行后续读取。必要依赖查询失败或图展开超过100节点导致明确预检失败，不能把未检查完的图当成功快照。worker报告读取失败终止构建；只有当前lease能发布终态和相关失败通知。

公共全局目录仅读取源mod已批准的active ready/partial导出；已被拒绝/待审源不由全局入口展示。无导出snapshot的人工创建recipe type保持原有公开行为。跨来源资源解析只使用已批准来源；当前preferred revision可由已经授权的上游编辑/预览入口使用，调用方必须先执行资源权限检查。目录素材旁路和模型角色约束需结合对应正式文档。

## 审核配置与导入任务

审核设置缺失时保留既有初始化默认值；数据库读取失败、非对象JSON、无效类型或null开关不能禁用审核。业务调用采用全部相关开关开启的安全回退，管理员读取返回503，须修复配置后重试。通知模板运行时可使用内建源语言回退；管理员读取和更新前无法取得当前配置时返回503，不会以空配置覆盖已有模板。

模组导入的本地fallback只用于无Outbox且队列临时不可用；每个worker/API实例最多4个本地处理器，满额保留queued持久任务，由15秒扫描再次调度。任务显式disabled、上下文取消或进程关闭不能触发新fallback；领取仍由数据库原子状态控制。HTTP完成响应之后已提交任务允许继续处理，worker扫描任务绑定进程生命周期。多实例合计并发不是固定4个；NATS已有任务并发由队列配置控制。

导入事务在写manifest、删除旧staging或发布前锁定当前job/token与有效心跳；旧token、取消任务和迟到worker不能进入写入操作。部署应停止旧导入worker再启动新fenced版本（schema已有run_token，导入不另需迁移）；详细可见性与部署说明见 `../CONTENT_EXPORT_VISIBILITY.md`。ZIP恢复签名同初始上传禁止覆盖，且申报大小不能超过2GiB；对不可修改的已有key须重新上传新key，不能覆盖已登记产物。

配方批处理取消返回取消错误，不把已处理的部分内容当整体成功。全局导出事务按现有fence保护，任务仍通过持久状态呈现失败/恢复；不宣称对象存储、消息和数据库跨系统严格只执行一次。
