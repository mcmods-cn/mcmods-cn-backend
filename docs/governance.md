# 三仓维护与验收台账

工作分支均为本地 `governance/nov21`。本页记录本次变更的依据、复跑方式和待验事项；[系统地图](system-map.md)用于查业务和权限入口。[历史材料](history/README.md)保留既有证据。

## 起点与工作顺序

2026-11-21 用 `git ls-remote --symref origin HEAD` 核实三个远端均以 main 为默认分支。三份原始 checkout 均在单独的干净 work 分支，与下列阅读基线一致。

| 仓库 | 本次开始的 main |
| --- | --- |
| exporter | `c61c8f952a8833b88a4c1aefa7a976efb0149528` |
| frontend | `e9948fde232581705fcedecbbf2a23312b4be726` |
| backend | `21724a42fd0dd84935fa0b4b7cf75c123a191500` |

M0 核实三仓和七个业务域。M1 优先处理可能丢失已确认消息的配置回滚、授权有效期及供应商数据边界。M2 按导入发布和配置读取的事务/页面边界收敛。M3 用单节点实际 JetStream 和隔离 PostgreSQL 检验两实例投递、长任务与本地降级。M4 在访客、合成管理员和普通编辑者的实际浏览器界面验证。M5 核对生产 ZIP、消费投影、包校验器和维护入口。M6 在独立 checkout 复核并记录发布与恢复条件。

验证机为 Linux amd64，cpuset 允许 5 个逻辑核，cgroup CPU 配额为 4 核，内存上限 16 GiB。初始 Go 1.26.6、Node 24.19.0/npm 11.17.0、JDK 17.0.21.1/Gradle 8.8，初始 Next 16.3.8/React 19.2.4。PostgreSQL 18.6、Redis 7.4.11、NATS 2.11.17 由本次固定镜像及独立数据库启动；队列专项另使用 go.mod 固定的 file-backed nats-server。原包包括仓库记录 SHA 的历史 Fabric 样本，以及本轮在 Xvfb 中运行真实 Minecraft Fabric/JEI 产出的包。OSS 协议使用回环替身。真实供应商调用、邮件发送和线上部署不属于此次验证。

## 发布、回滚与恢复

1. 记录当前的应用镜像、Go/Node/JDK 版本、数据库 generation、加密密钥版本、三方公开 origin，以及管理面板显示的 stream 及未交付/死信数。备份 PostgreSQL，用独立实例试恢复。保留对象桶、NATS 持久卷、账号和进行中的任务。工作分支上的提交供评审后发布。
2. 先发布后端与 Worker，使用 go.mod 指定的修订版编译器。先核实 /ready、读取公开目录、拥有权限的五类配置读取及无权的 403。旧前端仍能按原聚合接口读取配置。更新全部提供认证的 API 副本后，时间限定权限的缓存修复才全面生效；如需在更新期间维持严格的到期边界，把流量集中到新版鉴权副本。核对 outbox 最老未交付年龄、重试、stream 空间及死信，再恢复日常任务流量。
3. 用相匹配的前后端 origin 构建并发布前端，检查一次真实分类搜索、退出、后台单面板重试和公开 PNG 重定向。失败的私有配置应显示重试。使用两个身份验证独立审核，公开浏览器验证图片像素与目录；成功上传的 ZIP 在状态页应能区分导入和审核。
4. exporter 分发可独立进行。保留支持的 v1 manifest、v7 JEI 和历史包兼容规则，记录新包 SHA-256、生产提交及加载器。完整导入链的每一轮验收须指明用的是哪一包。Fabric 的运行凭据和 Forge 的构建凭据分别登记。
5. 回滚时优先回退前端或客户端 Mod。遇到后端问题先把流量收回到验证过的副本，保留 DB、WAL、队列与对象。全面回退至旧 API 会恢复旧权限、图片和队列行为，需要运维评估后执行。服务端暂时停用消费者须保留数据库发件箱。NATS 断开时先确认现有本地配送与数据库租约，当目标状态不明，先定位 event_id/任务/供应商交付记录，再通过权限受控的恢复入口重试。[队列恢复手册](queue-recovery.md)
6. 配置读取失败先检查部署时的设置加密密钥、连接和真实存储内容；保留原密文并用相应密钥恢复。在隔离副本验证后再处理遗留设置。已被业务事务墓碑标记的原包需等待签名到期、引用检查和对象删除任务。未知计费或邮件交付需要核对供应商记录，再决定人工恢复。[文件字节绑定](audit-oss-byte-binding-upgrade.md) · [翻译结算](ai-translation-reliability.md)

环境私密文件、浏览器 cookie、预签 URL 和原始调试日志不随发布物分发。
