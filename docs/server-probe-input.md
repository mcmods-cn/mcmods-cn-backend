# Minecraft 探测输入与图标

服务器探测只连接已核对的公开 IP，状态包限制为 2 MiB；主动 Configuration 探测只在已有明确提交流程启用。服务端不以缓存 DNS 名称重新解析连接目标。

状态响应的 favicon 只接受 PNG data URI，编码长度最多1 MiB，解码字节最多768 KiB；读取PNG头前检查签名，再核对头部与每边最多512像素。常规Minecraft64×64图标保留。错误头、截断头或超大声明尺寸返回空图标，不影响其它服务器状态展示；不会先完整解码巨幅像素。

此检查限定状态图标输入，不等于完整PNG像素/第三方服务器内容质量验收。测试只用合成PNG和篡改IHDR+合法CRC，不对真实第三方执行攻击探测。
