# 站务页面语言与发布

`PUT /api/v1/admin/site-affairs/about/{locale}` 由 `site_affairs.about.manage` 保护。保存草稿只改变所选语言；母页面状态由已发布译文是否存在决定，其他已发布语言继续公开。没有已发布语言时公开接口返回 404。

管理 GET 的 `status` 和 `translationStatus` 均为所选语言的状态，`pageStatus` 为母页面状态；既有返回字段保留。一次保存使用母页面行锁串行化，并在同一事务更新译文和母页面。

管理写入仅接受当前支持的编辑语言，沿用 `normalizeContentLocale` 的现有别名规则；不支持的语言返回 400，不回退后覆盖中文。公开读取仍按请求语言、中文、英文及已有译文回退，响应 `locale` 指出实际内容语言。

站点更新记录同样拒绝不支持的写入语言，列表读取错误返回 500，不返回部分成功列表。此变更不需要 schema 迁移。
