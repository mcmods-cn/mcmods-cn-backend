# 资料与编辑权限操作的存储错误

头像绑定在事务前检查文件与动画权限，事务内重新核对并共享锁定活动、扫描可信且属于
本人的文件。不存在或不合格文件返回 400；读取存储失败返回 503，并保留原头像。
权限和文件归属要求不变，不需要迁移。

撤销项目编辑权限时，仅实际不存在的项目、账号或活动授权返回 404；查询失败返回 503，
修改失败返回 500，并回滚授权与审计。故障不会被显示为资源消失。

日志批次分享保留每项成功/失败结果。数据库读取或保存失败的消息使用固定脱敏描述；
已有分享查找故障不会被误判为缓存未命中，也不会继续读取原始 OSS 文件。用户可以重试
失败项，已成功的分享不重复创建。文件格式和大小错误仍返回原有可操作的说明。
