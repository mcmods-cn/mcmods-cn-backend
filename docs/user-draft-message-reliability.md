# 草稿、私信与目录查询的失败行为

Markdown 编辑器 GET 仅在用户尚无草稿（pgx.ErrNoRows）时返回空内容；数据库读取异常返回 500，防止前端将读取故障当作空草稿并自动保存覆盖旧内容。已有 GET/PUT URL 和成功响应结构保持兼容，配合前端加载失败后的重试和保存保护。

私信读取先检查参与者身份。已读写入失败返回 500，不调整未读缓存或发布成功事件；会话/消息结果迭代失败不会返回部分成功数据。发送前一次读取接收者 publicId 和隐私偏好，避免消息已落库后才读取接收者失败并误导用户重试。通知入队仍明确返回 notificationQueued；供应商和队列不保证端到端恰好一次。

文件额度查询失败返回 500，不显示用量为零。用户文件、整合包关联、作者关系、私密统计和反滥用结果检查迭代/读取错误，失败由调用链返回错误。活动清理完成状态记录失败返回明确 500；自动清理无法读取近期执行记录时停止本轮。删除已发生而完成记录失败时不会恢复已删数据，此状态需要管理员核对，不能将重复点击当作恢复方案。

皮肤审核响应的 revisionId 与其他内容审核一致，返回公开字符串 ID，避免泄露内部数值 ID并破坏前端类型契约。审核权限、事务、状态转移和重复审核冲突处理保持既有规则。

隔离 PostgreSQL 回归覆盖无草稿/已有草稿/读故障保留原内容，私信已读写入故障及非成员拒绝，额度读取故障，皮肤审核持久化/公开 ID/重复冲突。直接 handler 测试注入合成 claims，不能据此宣称完整登录中间件或浏览器旅程均已通过。无 schema/迁移要求，部署后端即可；本次不访问生产数据。
