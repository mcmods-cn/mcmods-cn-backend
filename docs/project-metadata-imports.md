# 项目元数据导入

元数据导入接口创建草稿任务，不会为提交者自动授予项目编辑权限。任务读取供应商元数据、
校验草稿并存入导入结果，最终项目提交仍走各项目的创建与审核入口。

任务通过事务外盒投递。领取使用 `queued → running` 条件更新；周期恢复处理遗漏外盒的
等待任务与超过五分钟未更新的执行任务。`started_at` 是本次领取的标记，恢复会清空它。
进度、成功和失败写入都核对该标记与执行状态，旧 worker 的迟到结果不会覆盖恢复后的
新尝试。领取数据库失败返回处理错误；失败状态持久化使用十秒的独立超时，并保留写入
错误，避免把未持久化的失败当成成功确认。

这不能保证外部供应商只请求一次：供应商响应与本地提交之间的崩溃、租约回收仍可能导致
重复读取。当前导入是有界元数据/归档读取；AI 翻译的费用预留与请求预算另见
[AI 翻译可靠性](ai-translation-reliability.md)。

供应商安全 HTTP 客户端在拨号时校验并固定解析出的目标地址，拒绝内网、链路本地及
共享地址范围。显式配置的回环测试服务只允许回环地址。该客户端不继承环境 HTTP(S)
代理，因为代理侧解析目标会绕过目标地址校验；此设置不修改全局网络或安装工具的代理。
只允许通过代理出网的部署需要先解决该专用客户端的直连条件，不能声称此模式已连通。
跨 API origin 的重定向会被拒绝，供应商凭据只发送给被配置规则认可的来源。

隔离 PostgreSQL 和本地 HTTP 测试验证正常任务、供应商错误、恢复投递以及迟到成功/失败
不覆盖新任务；本地代理回归验证环境代理没有接收到供应商请求。没有调用真实供应商，
也没有验证线上任务积压、供应商可用性或生产网络性能。
