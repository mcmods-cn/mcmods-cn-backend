# API 访问日志查询参数隐私

全局 API 访问日志保留方法、路径、状态、耗时及响应字节数。非空查询串的 `payload.query` 只写固定 `[redacted]` 标记；空查询串保持空字符串。Yggdrasil 查询串继续完全省略。查询参数名和值均不落库，以覆盖 OAuth code/state、会话凭据、签名 URL、私人搜索词、未知参数和畸形编码；不能用敏感字段名称黑名单保证安全。

这仅改变日志元数据，传给业务 handler 的原查询参数和 HTTP 响应保持不变，不更改 API/schema，不需要迁移。通过新建、带身份标记的隔离 PostgreSQL 数据库验证实际 logAccess → writeAppLog → app_logs 写入，断言业务原查询不变和日志不含查询内容。

部署后只保护新写入。历史日志是否含凭据未查询生产、未清理真实数据；若需检查、清理或轮换真实凭据，必须在明确授权及适用保留要求下执行。该规则不能证明路径、其它日志 payload 或外部访问日志都不含敏感信息，仍需按各自写入链路检查。
