# 货币转账响应与权限

`POST /api/v1/users/me/economy/transfer` 沿用登录与 `economy.transfer` 权限、活动货币、余额锁与同事务双边流水。
响应包含币种、发送金额、税额、到账金额和发送者余额；不返回收款者已有钱包余额。
收款者通过自己的经济概览读取余额。转账金额、税率、并发扣款及账本规则没有改变。

商店购买和使用道具复用认证中间件解析的完整权限规则，保留优先级、精确权限与拒绝规则。
持有交易事务时，图片设置及热度目标查询使用同一事务连接，不再向已被占用的单连接池申请第二条连接。
商店列表先完成权限解析再读取列表。用户头像先做所有权与格式/动画检查，进入写事务后重新核对并锁住文件，
避免外部动画读取占用用户行锁；受保护的动态头像仍需原有独立权限。

隔离 PostgreSQL 回归验证收款方余额隐私、税额/账本与双方实际持久化，以及单连接池下头像、商店和旧 OSS 删除入口。
生产余额、流水完整性、真实对象存储连通性与运行负载未在本任务访问。
