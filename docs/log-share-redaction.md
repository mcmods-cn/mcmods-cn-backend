# 日志分享脱敏规则与历史版本

日志分享在发布前处理已知敏感字段，包括裸键和单/双引号键、包含空格和转义引号的完整引号值，以及 OAuth code/state 和常用签名 URL 参数。正常日志上下文保留，脱敏后仍不应假定日志中所有未知格式或所有个人信息都已识别。

本次规则版本为 2。新文件分享按既有 source_file_id/redaction_version 活跃唯一索引重新生成，不复用版本 1 的存储结果。现有 SQL 默认版本 1 不改写；应用新建分享显式写入当前版本，无 schema 迁移。

公开查看和下载旧版本分享时追加当前规则，并重新计算本次返回的 byteSize、lineCount、checksum。redactionVersion 和 redactionCounts 仍表示存储时的版本与统计；新增 appliedRedactionVersion 表示本次响应采用的规则。该读取保护不回写、删除或扫描历史真实数据；旧响应或浏览器已保存的文件无法追回。

查看/下载继续 no-store，沿既有到期、删除与归属权限规则。确定性测试涵盖 JSON/单引号/空格/转义、裸 token、OAuth/签名 URL、正常上下文以及专属 PostgreSQL 中创建和公开读取分享；合成旧版本内容在展示时受到保护且原存储内容保持不变。未调用真实对象存储，也未进行生产日志清理。
